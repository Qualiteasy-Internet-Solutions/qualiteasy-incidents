# Panell municipal i alta de brigada

Inicia `dashboard_server.py` amb Zammad a `http://127.0.0.1:8084` i un token de prova a `../.zammad-api-token`. El panell es mostra a `/demo` i el formulari simple a `/`.

Els canvis de tiquet s'escriuen a Zammad. Les metadades de flux, avisos simulats i la NC de demostració es guarden en un SQLite local que no es versiona. Els perfils són simulats i aquest servidor només s'ha d'utilitzar a localhost. Les imatges incloses són sintètiques.
